# What's For Dinner - Random Recipe Picker

Click a button, get a random meal with its ingredients and steps.

**Stack:** JavaScript, HTML5, CSS3

**Live demo:** https://hazemdev-1.github.io/whats-for-dinner/

## Features

- Meals stored as an array of objects (meals.js)
- Random selection and dynamic rendering with DOM manipulation
- Practice of functions, objects and arrays

## Run it

No build step. Open `index.html` in a browser, or use the VS Code Live Server extension.
